## Geometry and shared composition

- Originals: PC 1487×1058, Mobile 853×1844. Actual browser targets: PC 1440×1024 CSS px; Mobile 390×844, DPR 1. Original→CSS width factors: 0.9683927 and 0.4572098. Do not scale the application itself.

Header title starts y≈23, first card y≈105; pages with secondary tabs start main card y≈155. Top cards/rows are visually substantial, not compact utility widgets.
- Desktop cards have hairline borders, restrained navy surface gradient, 12px corners, 24px interior padding. Common 2-column splits are roughly 62/38 (forms+summary), 67/33 (overview chart+monitor), 38/62 (monitor facts+chart), or 32/68 (market list+chart). Use minmax(0,…) so long Korean cannot force overflow.
- Mobile original horizontal gutter is ≈28–40px (≈13–18 CSS px); normalize to 16px. Content width≈358 CSS px. Fixed bottom tabs are ≈55–66 CSS px tall, plus safe-area. Allow scroll; reserve bottom clearance. Header is title/back action plus environment/time metadata; do not squeeze all right-hand desktop header controls into a single mobile row.
- Tokens: background #101721; surface #141E2A; alternate #18222E; primary text #E6EDF6; secondary #AEBACB; primary action #3665EA; profit/up #FF6B7A; loss/down #76A1FF; healthy #48D8B1; caution #F6BD4F; divider #2B394C; input #121C28, border #697E9A.

## Differences requiring explicit exceptions

Generated sources cannot all be literal truth simultaneously. Desktop menu counts and mobile trading icons change between images. Daily changes differ across 01, 02 and 05 and between desktop/mobile; share one canonical market response, using 02 values above. Some generated desktop chart current labels are blue even for positive moves; standardize semantic chart colors. Reflow long content instead of decreasing type size. Account scope remains read-only real account and never receives a global PAPER context. Actual RULE recommendations, unconfigured providers, unknown data and unsupported actions must show their real state; the visual fixture alone can show labelled examples. Mobile overview/paper/monitor intentionally omit the desktop chart. Record those exceptions; do not claim pixel identity.
