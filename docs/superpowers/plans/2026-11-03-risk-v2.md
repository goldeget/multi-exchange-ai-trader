- 이름은 가상 `XAAUSDT`/`YBBUSDT`, source_environment=`FIXTURE`, NOW는 exact UTC 고정값이다. source row는 A02 strict schema를 완전히 채운다. `priceScale`은 문자열 `"1"`, tick/step/minQ `0.1`, min amount `5`, LIMIT maxQ `10`, MARKET maxQ `0.9`, leverage `1..150` step `0.1`을 사용한다. 숫자는 예제 거래소 상수가 아니다.
- 기본 LONG: limit `100`, stop `90`, fee/base `1`, funding/base `0.5`, stop-gap/base `0.5`, per_trade_loss `12`. Q=`1`, loss=`12`, cost=`2`, funding=`0.5`다. SHORT는 floor `100`, stop `110`이며 같은 Q를 가진다.
- quote/evidence age `2`/`10` seconds, capacity `60`, buffer `0.01` 등은 이 고정 fixture의 입력이다. 실제 설정/TTL로 저장하지 않는다. fee/funding/gap/minimum/margin/liquidation revision은 명시 `FIXTURE_*` ID로 구분한다.
- 최소금액 평가는 fixture rule에서 Q×`95`=`95`로 주어 mark/limit/minimum 세 값을 의도적으로 다르게 한다. 이것이 Bybit의 실제 minimum 공식이라는 주장은 하지 않는다.
- 첫 import가 없는 새 module에는 최소 importable stub만 두고 행동 test가 `NotImplementedError`/잘못된 결과로 RED임을 확인한다. collection error/SDK unavailable만으로 RED를 인정하지 않는다.

각 task의 좁은 RED→GREEN 후 touched files에 Ruff/strict mypy를 수행한다. 필요 없는 같은 broad test 반복은 피하고, 모든 core 변경이 끝난 정확 SHA에서 한 번 covering regression을 실행한다. repository 전체/native/restart/restored-monitoring/frontend/browser/operations는 root의 기존 exact hosted CI가 최종 소스 회귀를 소유한다. local Windows skipped/native 미실행을 PASS로 보고하지 않는다.
