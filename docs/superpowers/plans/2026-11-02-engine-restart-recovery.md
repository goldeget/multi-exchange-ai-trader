**Interfaces:**
- Store exports frozen `NativeRestartIdentity(scope: ProtectionScope, native_account_id: str, trader_id: str, strategy_id: str, instrument_ids: tuple[str, ...], native_version: str = "1.231.0")`, fixed-redacted `NativeRestartError(ValueError)`, frozen `NativeRestartGeneration`, `application_digest(directory: Path) -> str`, and `NativeRestartStore(directory: Path)`.
- Store methods: `load(identity: NativeRestartIdentity) -> NativeRestartGeneration | None` validates sealed file and exact app digest; `mark_active(identity: NativeRestartIdentity, generation: NativeRestartGeneration | None) -> None` atomically consumes exact generation or creates bootstrap active marker only when no file exists; `seal(identity: NativeRestartIdentity, payload: dict[str, object]) -> NativeRestartGeneration` publishes fresh seal binding current app digest. Filename `native-restart.json`; sealed/active are explicit states. Generation exposes native `payload`, `generation_id` and `application_digest`. Store validates exact file/schema/identity, bounded canonical content/hash and state; no native dependency imports.
- Codec exports `capture_native_cache(cache: Any, *, identity: NativeRestartIdentity, owners: tuple[OwnedCacheExpectation, ...], allowed_missing_ids: frozenset[str] = frozenset()) -> dict[str, object]`, `prepare_native_cache(payload: dict[str, object], *, identity: NativeRestartIdentity, owners: tuple[OwnedCacheExpectation, ...], allowed_missing_ids: frozenset[str] = frozenset()) -> PreparedNativeRestart`, and `install_native_cache(cache: Any, prepared: PreparedNativeRestart) -> NativeRestartResult`. Preparation fully decodes/validates into an isolated candidate and does not touch the target or app; caller consumes the seal before installation. Frozen result has `status="RESTORED_LOCAL_CACHE"`, counts for orders/positions/missing owned orders and `production_supported=False`. Actual SDK imports lazy/version-checked. Reuse existing immutable `OwnedCacheExpectation` data but do not reuse its active-only inspector as restore gate. Only IDs explicitly listed in `allowed_missing_ids` may be absent; all must be owners, and a required Position source order may never be absent. Coordinator derives this set solely from validated PENDING/SENDING/UNKNOWN records; ACKNOWLEDGED/known source orders missing from native generation block.
