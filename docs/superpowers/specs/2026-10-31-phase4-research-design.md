## Risk-controlled local automatic PAPER

Use a **single Phase4 SQLite transaction** for session state/journal/native replay results; do not write to the existing manual PaperStore at all. Original PaperStore DB/schema/16scenario/500event contract remains untouched. A new Phase4 run independently enforces16sessions/500native events and bounded80sourcebars. This is pure socket-denied native replay: execution has no external effect or separate persistent engine DB, so a crash before commit safely discards/recomputes the candidate. No unnecessary two-DB saga is introduced. If future code introduces a second persistent effect, durable fixed-key intent reconciliation becomes mandatory before acceptance.

The runner advances prerecorded synthetic event time at a disclosed minimum1second cadence after completed steps, independent of wall-clock/real markets. Start/pause/resume/stop controls have fixed PAPER mode. Persist configuration/dataset hash/cursor/status/native event list/result plus append-only hash-linked audit and idempotency results atomically using BEGIN IMMEDIATE. Same key/payload returns the original committed result, conflict rejects. Test faults after actual native replay/before SQL commit and after commit/before HTTP response. Cache is reconstructed by native replay, never a custom matcher.

Restart always recovers nonterminal sessions as **PAUSED_RECOVERY**, never auto-restarts trading. Startup/read verifies committed state without processing another event. Explicit resume continues at the committed cursor. Run lock and recorded next-due time/expected cursor serialize duplicate loops and pause/stop/inflight races. Pause waits for an inflight transaction to settle; once acknowledged no subsequent steps occur. Stop flattens actual native positions once, is terminal and idempotent. Single local API/scheduler process only; multi-worker deployment unsupported.

Bound source to at most80bars per session; at most6ordinary native events/bar. Reserve **10events** for terminal native exits/recovery; refuse an ordinary step if event_count+6+10>500. Terminal flatten uses this reserve rather than creating a new scenario/resetting funds. Enforce16sessions and cleanly refuse excess. Preserve gap losses/negative cash. Historical synthetic source timestamps and local receipt time are separate; native PAPER_REPLAY_V1 is explicitly synthetic, not an exchange clock.

Default independent limits: maximum exposure1000virtualUSDT, total loss5% initial equity, maximum drawdown5%, consecutive losses3, max events bounded by native replay limits. Reject unsafe entry quantities before native submission. On a loss/drawdown/streak/event/data boundary, halt and submit native reduce-only flatten where possible; preserve adverse gap overshoot/negative cash, never erase it. Pause prevents new steps/orders and does not imply closing an existing position; stop cancels/flat closes once at the last synthetic quote and is terminal. Surface cause/current cursor/source/last virtual event time/exposure/realized-unrealized/fees. Stop is idempotent after recovery. No external market collector is part of the runner.
